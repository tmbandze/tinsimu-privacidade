# Política de Privacidade — Tinsimu Ta Kutwanana

Página pública da política de privacidade da aplicação
**Tinsimu Ta Kutwanana** (hinário digital da Igreja do Nazareno em
Moçambique), exigida pela Google Play Store.

Publicada em: https://tmbandze.github.io/tinsimu-privacidade/

Este repositório existe só para alojar esta página. O código da aplicação
está noutro repositório, privado — as partituras digitalizadas e as letras
não podem ser públicas.

## Como actualizar

A fonte é `docs/privacy.html` no repositório da aplicação. Depois de a
alterar lá, copiar por cima do `index.html` daqui e fazer commit. O GitHub
Pages publica sozinho em cerca de um minuto.
